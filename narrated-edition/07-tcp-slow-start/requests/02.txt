[warmly] Sending something is not the same as knowing it arrived. So the receiving computer sends a small reply meaning, I've received data up to this point. That reply is an acknowledgment, shortened to ACK. Watch blue data go right and a green reply return left. We will draw one reply for each piece to keep the idea clear. Actual TCP can acknowledge several pieces together. The returning replies give the sender evidence of progress instead of making it guess blindly.
