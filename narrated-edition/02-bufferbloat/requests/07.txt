[warmly] Here is a tempting fix: make the waiting room bigger. Surely more space means a better connection? [short pause] [warmly] Watch carefully. The room expands, but the door stays exactly the same. It still sends the same number of bits each second. Extra memory lets more packets wait inside. It does not make their turns finish sooner. A bigger room can be useful for a short rush. But if we keep it full, we have built a longer wait, not a faster exit.
