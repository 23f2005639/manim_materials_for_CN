# References — How Does a Download Discover Its Speed?

Sources checked while writing the teaching script; narration is original.

- [RFC 5681: TCP Congestion Control](https://www.rfc-editor.org/rfc/rfc5681) — Slow-start ACK-based growth, congestion window and threshold; the doubling picture explicitly assumes one useful ACK per full segment.
- [RFC 6928: Increasing TCP's Initial Window](https://www.rfc-editor.org/rfc/rfc6928) — Initial windows are not universally four segments; larger choices were experimentally specified. Four is an illustrative starting point here.
