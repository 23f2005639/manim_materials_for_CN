# YouTube narration revision

All eight original scripts use plain English for a general audience. Each opens a concrete question, builds the explanation through the existing diagram, and returns to the question at the end. Classroom, assignment, and exam framing has been removed. Narration points to visible changes, then explains their cause.

The general visual-discovery approach was informed by the official [3Blue1Brown Fourier-transform video companion](https://www.3blue1brown.com/lessons/fourier-transforms/). The [Hamming-codes lesson page](https://www.3blue1brown.com/lessons/hamming-codes/) also identifies its discovery-oriented approach. The full Fourier article was read; the Hamming page supplied a description and video reference rather than a transcript. These sources informed the teaching structure; narration is original and uses the existing networking examples.

All 192 scene titles, order, durations, technical examples, and animation data are unchanged. Presenter notes and guide captions match the revised scripts. All 201 network MP4 files match the saved SHA-256 hashes. No video rendering or export was performed.
